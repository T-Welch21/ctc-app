What's Built

Features shipping in v1

Everything that's live and working right now in the app.

🔐
Supabase Auth
Email/password signup with password reset. Profile syncs to Supabase with localStorage fallback for offline use.
⏱
Rest Timer
Automatic countdown between sets. Pause, skip, dismiss. Phone vibration when rest is over. Reads rest time from each exercise.
📝
Exercise Notes
Log weight and notes per exercise during a session. Shows "last session" hints so athletes remember what they lifted.
📊
Weight Trend Chart
SVG line chart with gradient fill showing last 14 weigh-ins. Change indicator shows progress from previous entry.
👥
Live Athlete Roster
Command Center pulls athlete profiles from Supabase in real time. Shows active/new badges, join date, refresh button.
📱
PWA + Offline
Service worker, app manifest, installable on home screen. Dual storage: localStorage for instant/offline, Supabase for cross-device sync.
🏆
Session Celebration
Trophy overlay when all sets are completed. Shows session title and total sets crushed. Session data saved to storage.
📖
Daily Journal
Morning/evening toggle. Energy and mind sliders. Needle movers checklist. Gratitude prompt. Daily affirmation rotation. Full history.
